# BIA Email Signature Generator

A static GitHub Pages-ready email signature generator customized for the Bureau of Indian Affairs (BIA), U.S. Department of the Interior.

## Included fields
- Full Name
- Job Title / Position
- Office / Division
- Region / Agency / Field Office
- Duty Station
- Phone Number
- BIA Email
- Optional FireNet Email

## Features
- Live BIA-specific preview
- Download signature as PNG
- Copy PNG to clipboard when browser support allows
- Responsive layout
- No backend or dependencies

## Publish with GitHub Pages
1. Create a GitHub repository such as `BIA-Email-Signature-Generator`.
2. Upload the contents of this folder to the repository root.
3. Go to **Settings > Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/(root)`, then save.

## Branding
The included circular BIA text mark is a neutral placeholder drawn by the application. It is not represented as an official BIA seal or approved branding asset. If your office provides an approved logo/seal and official email-signature specifications, replace the placeholder and update the template accordingly.
